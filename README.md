**Calculadora Moderna em JavaScript**

Uma aplicação de calculadora limpa, moderna e responsiva, desenvolvida sem o uso de frameworks, focada em boas práticas de manipulação do DOM e lógica de programação.

---

**Funcionalidades**

- Operações aritméticas básicas e avançadas (Soma, Subtração, Multiplicação, Divisão, Porcentagem e Inversão de Sinal).
- Histórico dinâmico das últimas operações com opção de limpeza.
- Suporte total ao teclado (Atalhos para operadores, Enter, Backspace e Esc).
- Alternância de Tema (Claro / Escuro) com persistência visual.
- Tratamento robusto de erros (Divisão por zero, múltiplas vírgulas e overflow).

---

**Tecnologias Utilizadas**

- HTML5 (Estruturação semântica)
- CSS3 (Variáveis CSS, Grid Layout, Flexbox e Design Responsivo)
- JavaScript (Lógica de estado, manipulação de eventos e teclado)
